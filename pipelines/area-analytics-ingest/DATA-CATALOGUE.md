# Public data catalogue

Every production release records a retrieval timestamp, publisher release date,
SHA-256, licence, attribution, geography vintage, transformation version,
caveats, and validation result. The enforceable record is the reviewed source
registry in `area_analytics/sources.py`; this catalogue summarises it. A source
is blocked by default and enters an active release only with an approved licence
decision, a committed government-shaped fixture, and a reviewed distribution URL.
An undated download is never eligible for publication.

Competitor ratings and scraped commercial listings are not eligible sources and
have no registry entry, so acquisition rejects them as unknown sources.
A blocked source cannot enter an active release: enabling one needs an approved
licence decision plus a committed, government-shaped test fixture, after which
its Review column moves to Active in the same change.
