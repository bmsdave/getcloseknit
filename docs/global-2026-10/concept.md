# Глобальный слой Close Knit: концепция (октябрь 2026)

Черновик на ревью владельца. Кода нет. Деньги, прогноз и фичи: [strategy.md](strategy.md). Доска: [G1 · уровни зума и Compare places](G1-global-zoom-compare.dc.html) (для холста Claude Design, страница `global`).

## Суть

Карта, где можно сравнить страны, регионы и города, а там, где у нас есть локальные данные, спуститься до районов. Отличие от Numbeo: только официальные открытые данные, у каждой цифры источник и тип, и **метрика видна только там, где она сравнима**.

## Главные правила

1. **Метрика только на сравнимом уровне.** Если источник меряет одинаково во всех местах уровня, метрика есть. Если нет, чип зачёркнут с причиной («методики разные»). Сравнение «внутри одной страны» разрешено, если все места из одной страны.
2. **Преступность между странами = только убийства на 100k (UNODC, через WDI; лицензия под вопросом, см. инвентарь).** Полицейская статистика сравнивается только внутри страны. Индексы «восприятия» (Numbeo) не используем. Опрос ЕС «Quality of life in European cities» можно показать как «Чувство безопасности (опрос ЕС)», это восприятие, а не преступность. Решение владельца.
3. **Цена за м² всегда с меткой источника и уверенностью:**
   - `Сделки` ●●● — зарегистрированные продажи (HMLR, DVF, Kadaster, нотариусы Испании).
   - `Объявления` ●●○ — цены предложения порталов, выше сделок, выборка неизвестна.
   - `Индекс` — только изменение (BIS, OECD, Eurostat HPI), никогда не €/м².
   - Если в сравнении метки разные: показываем обе цифры и пишем «Не одно и то же: сделки и объявления». Ранжировать между разными метками нельзя.
4. **Нет общего балла между странами.** Сравнение показывается строками, каждая со своим источником. Свой порядок важности пользователь задаёт профилем.
5. **Деньги не влияют на данные, порядок и ответы MCP** ([monetization.md](../growth-2026-10/monetization.md)). Партнёры только в Next steps, с пометкой.
6. **Ограничения = флаги** ([FLAGS.md](../../FLAGS.md)). Предлагаемые флаги в конце; в FLAGS.md их добавим в той же правке, что и код.

## Спорные границы

- Линии из Natural Earth (вид по умолчанию, de facto). Спорные территории (Крым, Кашмир, Западная Сахара, Северный Кипр, Косово, Палестина, Тайвань, Аксайчин и др.) штрихуются без заливки, подсказка «Спорная территория: значения не присваиваем».
- Значения страны не распространяем на спорную часть. Данные источника (World Bank, UNODC) берём как есть, с примечанием источника о границах.
- Локальные «точки зрения» (Индия, Китай и др. требуют своих границ по закону) — флаг `CLOSE_KNIT_GLOBAL_LOCAL_POV`, по умолчанию выключен. Включаем только при выходе на такой рынок и после юриста.
- Названия: английские экзонимы + локальное название в подсказке; спорные с двумя названиями.

## MCP: «сравнить места»

Конверт ответа как сейчас: `value, confidence, evidence[], sources[], caveats[]`. Новое: у каждой метрики `level`, `sourceType` (`transactions | asking | index | survey | model | official`) и `comparable` (`true | within_country | false`).

| Инструмент | Что делает |
|---|---|
| `search_global_places` | имя → место с уровнем (страна/регион/город/район), id, есть ли районы |
| `compare_places` | 2–5 мест одного уровня → таблица метрик; несравнимые строки с `comparable=false` и причиной в `caveats`; разный уровень → предложение поднять до общего |
| `rank_places` | места уровня по одной метрике, только если `comparable=true`, иначе отказ с причиной |
| `get_place_profile` | одно место: все метрики уровня, источники, год, что скрыто и почему |
| `match_places` | профиль-концепты (ниже) → города, где они лучше всего выполняются; концепты без данных на уровне пропускаются и перечисляются |
| `list_global_metrics` | метрики, уровни, источники, лицензии, тип источника |

Правила для ассистента в инструкциях сервера: не сводить строки в общий балл, не называть объявления ценами сделок, преступность между странами только убийства.

## Переносимый профиль (вместо `#profile=v3`)

Сейчас `#profile=v3.` хранит id лондонских слоёв (`["r", "air-no2", …]`), поэтому профиль не переносится в другой город. Предлагаемый `#profile=v4.`:

- критерий = **концепт**, а не слой: `["k", concept, direction, importance, must]`; концепты: `safety`, `green`, `schools`, `commute`, `air`, `quiet`, `price`, `cost_of_living`, `health`, `climate_heat`;
- места = координаты + тип (`work`, `school`, `friends`), не id лондонских мест;
- бюджет с валютой: `["£", 1200000]`;
- старые `["r", layer …]` остаются для точной настройки внутри рынка (Лондон) и игнорируются в других.

Резолвер концепта: на каждом уровне и рынке берёт лучшую сравнимую метрику (таблица на доске, раздел 5). Если метрики нет, концепт пропускается и это сказано («Школы: нет сравнимых данных для городов Испании»). Переход v3 → v4: каждый лондонский слой сопоставлен концепту, v3-ссылки продолжают открываться.

## Деньги, инвестиции, путешествия: что можно честно

- **Стоимость жизни:** только уровень цен по стране (World Bank ICP PPP, Eurostat PLI). Открытых данных по городам нет; это место, где Numbeo сильнее. Не изобретаем.
- **Инвестиции:** изменение цен (индексы BIS/OECD/Eurostat) и валовая доходность аренды только там, где цена и аренда из официальных источников одного рынка (Лондон: HMLR + ONS; Париж: DVF + OLL). Иначе «нет данных». Не инвестиционный совет (ни FCA, ни AMF).
- **Путешествия:** открытых цен на отели и еду по городам нет. Вне MVP, флаг `CLOSE_KNIT_GLOBAL_TRAVEL_COST` (блокер: источник с лицензией).

**Что из этого следует:**
- IMF не берём: макро из WDI, OECD, Eurostat.
- Убийства — ключ правила 2, а условия UNODC запрещают коммерцию. Берём ряд WDI и держим за флагом `CLOSE_KNIT_GLOBAL_HOMICIDE`, пока World Bank или UNODC письменно не подтвердят повторное использование.
- WHO не берём: PM2.5 из CAMS или GHSL UCDB, продолжительность жизни из WDI/OECD. Данные WHO только за флагом `CLOSE_KNIT_GLOBAL_WHO_DATA` после разрешения.
- Eurostat для Великобритании не используем (некоммерческое для стран вне ЕС): Великобритания из ONS.
- OSM/Overture (ODbL): если MCP отдаёт производные объекты, это может требовать share-alike. Отдаём агрегаты по местам, не объекты; юристу тот же вопрос, что и для Лондона.
- BIS: API для пользователей остаётся бесплатным.

## Предлагаемые флаги

| Флаг | По умолчанию | Что держит | Блокер |
|---|---|---|---|
| `CLOSE_KNIT_GLOBAL` | off | весь глобальный слой и MCP-инструменты | ревью владельца + лицензии из инвентаря |
| `CLOSE_KNIT_GLOBAL_ASKING_PRICES` | off | цены объявлений с меткой `Объявления` | разрешение портала на отчёты |
| `CLOSE_KNIT_GLOBAL_HOMICIDE` | off | убийства на 100k (WDI, источник UNODC) | письменное подтверждение World Bank или UNODC на коммерческое повторное использование |
| `CLOSE_KNIT_GLOBAL_WHO_DATA` | off | данные WHO (GHO, AAQ) | разрешение WHO; пока PM2.5 из CAMS/GHSL |
| `CLOSE_KNIT_GLOBAL_PERCEIVED_SAFETY` | off | «Чувство безопасности (опрос ЕС)» | решение владельца (правило 2) |
| `CLOSE_KNIT_GLOBAL_LOCAL_POV` | off | локальные границы для отдельных стран | юрист при выходе на рынок |
| `CLOSE_KNIT_GLOBAL_TRAVEL_COST` | off | стоимость поездки по городам | открытый источник с лицензией |

## MVP на 3–5 недель

Исходим из варианта A (города Европы). Всё за флагом `CLOSE_KNIT_GLOBAL`, Лондон не трогаем. Код начинается только после согласования доски.

| Неделя | Что | Готово, когда |
|---|---|---|
| 1 | Данные стран и регионов: World Bank WDI (убийства за флагом), CAMS, OECD Regional (TL2/TL3), Eurostat NUTS 2/3. Границы: Natural Earth, GISCO NUTS. Таблицы `global_place`, `global_metric` (уровень, `sourceType`, `comparable`, год, лицензия). Строки в DATA-LICENCES.md | каждая цифра с источником, годом и лицензией; спорные территории без значений |
| 2 | Города: ~80 городов ЕС + Великобритании (Urban Audit ∩ GHSL UCDB, контуры FUA): зелень, PM2.5, жара, плотность. Цена за м² из сделок: Великобритания, Франция (DVF, без индексации), Испания (ERI по провинциям) | для каждого города видно, какие метрики есть и почему нет остальных |
| 3 | Веб: карта мира с лестницей зума, зачёркнутые чипы с причиной, панель Compare (2–5 мест одного уровня), метки `Сделки/Объявления/Индекс`, ☰ источники. Переход в районы Лондона | e2e: сравнение трёх городов, несравнимая строка с причиной, переход в Лондон |
| 4 | MCP: `search_global_places`, `compare_places`, `rank_places`, `get_place_profile`, `list_global_metrics`. `#profile=v4.` на концептах; v3-ссылки открываются | 20 вопросов «сравни X и Y»: нет общего балла, правильные оговорки, преступность только убийства |
| 5 | Запас: сверка с источниками, проверка границ, тексты, тайлы, ревью владельца | владелец посмотрел на проде за basic-auth |

**Не в MVP:** районы вне Лондона (Париж — следующий шаг), цены объявлений, стоимость поездок, Next steps для экспатов, локальные границы, `match_places`.

**Риски:** лицензии с пометкой «не проверено» (держим за флагами), DVF нельзя индексировать (страницы городов Франции без цены в sitemap или `noindex` для блока цены), объём тайлов мира (упрощённая геометрия по зуму), соблазн общего «рейтинга городов» (правило 4).
