For the implementer
  • your-search / personal-match-panel: render the three rows (Budget, Travel to, What matters) as the empty state; drop the wizard route and its components.
  • Chips + cards: one list (criteria-editor), one open card at a time; simple level by default, Fine-tune = the 30b card (criterion-focus).
  • Budget card writes targetBudget / maximumBudget; buy = typical area price (by type when Flat/House is picked), rent = by bedrooms as today. Never a per-home value.
  • Defaults table above lives in one place (lib/match-ranges.ts); the API scores every chip with the same soft-edge utility (Task 21).
  • Soften: client-side step on the cutting criterion + toast with Undo (Task 10). Importance = list order (drag); weights from rank, see V4-21b.
  • Old profiles and #profile=v1 links migrate as in Task 21. e2e: open → budget → map coloured; chip add; Soften + Undo; Fine-tune shows edges.
