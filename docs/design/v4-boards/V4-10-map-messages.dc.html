  • Add one shared MapToast (+ a tiny store: showMapToast(text, {link, ms})); move location, base map, “Pick at least one” and copy link onto it, with the exact wording in the list.
  • Phone: top = search pill bottom + 8px, left/right 10px gutters; desktop: top-centre of the visible map (panel excluded), max 520px. Never in the thumb zone.
  • role="status", aria-live="polite"; one at a time, newest replaces; ✕ is a 40px target; auto-hide 6 s (paused on hover/focus).
  • Locate: spinner ring while waiting; success = blue dot + accuracy circle, button filled, no toast. Denied (code 1) → toast + “How to allow”; unavailable/timeout → toast only.
  • Z-order token above controls, legend and sheets, below modal dialogs. Colours: --ink / --on-ink (inverted panel), so Night is light on navy.
