  • Below z13 the tiles have no points: add a density tile (trees per grid cell) or start the heat at z13.
  • Radius by zoom: ["interpolate", ["linear"], ["zoom"], 10, 10, 13, 18, 15, 28]; intensity 0.6 → 1.4; colour = green ramp, transparent at 0, max opacity 0.7.
  • Hand-over: heatmap-opacity 0.7 at z15 → 0 at z16; tree circles minzoom 15.5, opacity 0 → 1 by z16; size by canopy, hollow when null. Popup unchanged.
  • Order: tree heat lowest (under collision heat, lines, labels and markers). Collision heat keeps the warm ramp; legend lists both when both are on.
  • Green streets (Layers) is a separate line layer: one score per road link (trees per 100 m). The heat here is raw tree density, any direction.
