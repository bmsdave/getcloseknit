# AI assistant stores and directories for third-party MCP servers, apps and agents (as of 22 Oct 2026)

Scope: places where a third party can publish an MCP server, app, plugin, connector, GPT, Gem, skill or agent that end users can browse.
Method: web search on 22 Oct 2026. Many claims come from secondary blogs. **[U]** means unverified: one secondary source only, conflicting sources, or carried over from before 2026.
Relevance is for Close Knit, a UK/London neighbourhood-data product that already runs a remote MCP server and a Claude plugin. H = high, M = medium, L = low.

> **Correction (2026-10-22):** As far as we can check, Close Knit is **not** in Claude's Connectors Directory or plugin marketplace yet. A connector search shows `getcloseknit.com/mcp` only as the owner's own custom connector (no description, no icon), and the plugin lives only in the repo. Submission checklists: [chatgpt-app.md](chatgpt-app.md).


Openness levels: **open** (self-serve submission plus review), **custom-only** (users can paste any MCP URL but there is no public directory to submit to), **partners**, **enterprise**, **waitlist/preview**, **none**.
