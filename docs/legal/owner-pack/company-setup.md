# Company setup: Ltd → ICO → store trader status → trade mark

Draft for the owner. Costs checked on GOV.UK, ico.org.uk and the store help pages on
2026-10-27. Recheck before paying.

| Step | Cost | Time |
|---|---|---|
| 1. Ltd at Companies House | £100 online; £50 a year for the confirmation statement | about a day |
| 2. ICO fee | £52 a year (£47 by direct debit) | 15 minutes |
| 3. Store trader status | Chrome Web Store $5 one-off (if not already paid) | days (verification) |
| 4. UKIPO trade mark | £205 for one class + £60 per extra class | 3–4 months if no objection |

## 1. Private limited company

1. **Verify your identity first.** Do this through GOV.UK One Login; it is free. Since 18 Nov 2025
   every new director must be verified to incorporate. You get a personal code.
2. **Check the name.** Use the [name availability checker](https://find-and-update.company-information.service.gov.uk/company-name-availability).
   A search on 2026-10-27 found no active "CLOSE KNIT LTD"; similar names are dissolved.
3. **Register online** at [gov.uk/limited-company-formation](https://www.gov.uk/limited-company-formation)
   for £100 (£124 by post). You will need:
   - limited by shares, one director (you), one shareholder (you, 100%);
   - you as the person with significant control;
   - model articles;
   - a registered office in England and Wales, and a registered e-mail address;
   - SIC code **63120 Web portals**.
4. **After registration:**
   - a business bank account;
   - Corporation Tax: tell HMRC within 3 months of starting to trade;
   - a diary entry for the yearly confirmation statement (£50).

Fees: [Companies House fees](https://www.gov.uk/government/publications/companies-house-fees/companies-house-fees)
(changed 1 February 2026).

## 2. ICO

Follow [ico-steps.md](ico-steps.md). Register in the Ltd's name. Then set `CLOSE_KNIT_CONTROLLER`
and `CLOSE_KNIT_ICO_NUMBER`.

## 3. Trader status in the stores

The EU rules (DSA) make stores ask whether you are a **trader**. Close Knit earns money through
the company, so declare **trader**. The store then checks and shows publicly the company name,
address, e-mail and phone. Use the Ltd's registered office and hello@getcloseknit.com. Don't
use your home address or personal phone.

- **Chrome Web Store:** one-off $5 developer fee. Declare trader in the developer dashboard
  ([trader disclosure](https://developer.chrome.com/docs/webstore/program-policies/trader-disclosure)).
  If the extension now sits in a personal account, move it to an account or group publisher
  the Ltd owns, or switch the account to trader with the Ltd's details. Keep the listing
  unlisted until the solicitor's review.
- **If the iOS or Android apps ship:**
  - Apple Developer Program for organisations: $99 a year, and it needs a D-U-N-S number
    (free from Dun & Bradstreet);
  - Google Play: $25 one-off, organisation account.

## 4. "Close Knit" trade mark (UKIPO)

1. **Search first.** Check the [trade mark search](https://www.gov.uk/search-for-trademark) for
   "Close Knit" and "Closeknit" in the classes below. It is a common phrase, so knitting brands
   may hold it in other classes. That is fine; what matters is a conflict in our classes.
2. **Apply in the Ltd's name** at [gov.uk/how-to-register-a-trade-mark](https://www.gov.uk/how-to-register-a-trade-mark):
   - 9: downloadable software, browser extension, mobile apps;
   - 36: real estate information services;
   - 42: online non-downloadable software, SaaS, API.

   One class costs £205 and each extra class £60, so these three cost **£325**. Add 35
   (business information and referral services) for £385.
3. **Right Start** (optional): £125 + £30 per extra class to have the application checked
   first, then the same again to proceed. Useful only if the search finds something close.
4. If no one objects, registration takes about 3–4 months. Renew every 10 years.
