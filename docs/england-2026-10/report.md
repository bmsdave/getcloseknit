## Не покрыто и почему

**Решение этого раунда: только Лондон**
- **Данные по отдельным домам:** точки продаж, страницы домов, участки INSPIRE, EPC по домам, стоимость за м² по домам. На диск прода (96 ГБ) не влезает: нужен сервер на 300–500 ГБ.
- **Время в пути** (R5, расписания TfL, 32 хаба), зоны, ULEZ/CC, список будущего транспорта. Источники только лондонские; для национальной версии нужны графы BODS и железной дороги.
- **Приём в школы и потоки из начальной в среднюю.** Документы по советам с разными лицензиями; GLA Schools Atlas покрывает только Лондон.
- **HMO, LDD, Opportunity Areas, Inside Airbnb, Planning Datahub, деревья и тепло GLA.** Национальных аналогов нет.

**Тяжёлые источники, отложены**
- **NDVI Sentinel-2 (доля зелени), кроны деревьев, GBIF, уровень «Green & trees» (nature-score).** Это 80–150 ГБ сырья и ~33k запросов к API. Национальные парки/OSM меряют другое.
- **Тексты отчётов Ofsted.** По PDF на каждую из ~100k проверок, это дни.
- **Фото Geograph.** 7 млн фото, около 1,4 ГБ на проде.

**Внешние причины**
- **Качество воздуха (Defra PCM 1 км).** UK-AIR весь день был на обслуживании. Повторить позже.
- **Преступность:**
  - по Большому Манчестеру police.uk не публикует данные;
  - у Gloucestershire нет 2026-02…08;
  - у Northumbria неполный январь.

  Эти районы показаны белыми пятнами.
- **Planning applications.** Набор на planning.data.gov.uk пуст.
- **Article 4.** Не опубликовано у 184 из 296 советов.
- **Conservation areas.** Нет у 15 советов, показано «неизвестно».
- **Советники:**
  - окружные (county) не загружены: нужна схема для county divisions;
  - у 131 из 6 834 wards нет результатов в Democracy Club.
- **CCOD/OCOD (собственники-компании).** Нужен ключ HMLR.
- **Шум самолётов вне Лондона.** Карты отдельные по каждому аэропорту.

**Урезано ради диска**
- £/м² до 2023 года вне Лондона показан раз в год, а не помесячно.
- Места с уверенностью ниже 0,6 вне Лондона не загружены (1,43 млн).

## Известные ограничения и долги

- **MCP и расширение пока лондонские.** Это открытые каналы, и пока сайт закрыт, они следуют публичным значениям флагов (PR #174), а `CLOSE_KNIT_ENGLAND` для них выключен. Включится вместе с публичным запуском, после пересмотра ICO/LIA (FLAGS.md).
- **Страницы рейтингов `/rankings/*`** остаются лондонскими. Региональные рейтинги умножили бы число URL.
- **Скорость:**
  - холодный value pack грузится 4–5 с, тёплый 0,3 с;
  - лондонский вид около 4,8 МБ;
  - точки школ по Англии (~20k) идут одним запросом.
- **Медленные пересчёты:**
  - `rebuild_good_schools_nearby` идёт ~1,5 ч на проде;
  - `rebuild_area_good_value` ~20 мин.

  При перезагрузке школ это повторится.
- **Легенды переписи** теперь общие на всю Англию, поэтому шаги цвета у Лондона сдвинулись. Сами значения не изменились.

## Следующие шаги

1. Сервер на 32–64 ГБ RAM и 300–500 ГБ NVMe, затем данные по домам для Англии.
2. Время в пути вне Лондона: сначала «до центра ближайшего города».
3. Повторить воздух (PCM), когда UK-AIR оживёт. Доля зелени через NDVI тайлами.
4. Ключ HMLR для CCOD/OCOD. Окружные советники.
5. Ускорить пересчёт «хороших школ рядом» и холодные value packs.
6. Решить про MCP и расширение для Англии к публичному запуску.
