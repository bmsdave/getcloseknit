# Data licences

The code in this directory is Apache-2.0 (`LICENSE`, `NOTICE`). The data a
deployment loads is **not** covered by that licence: every source below keeps
its own terms, and a public deployment must display the attributions exactly
as written. `deploy/tools/property-load.sql` records the same licences in the
release ceremony (`source_release.licence`) so `/api/v1/metrics` and the
methodology page can cite them.

## What a deployment must not do

- Sell or redistribute the address spine, the EPC extract or the raw OS/HMLR
  downloads; serve them only as evidence behind a sale or a home.
- Present the restated stock value as a valuation (it is a restated sale;
  every payload carries that caveat).
- Remove or paraphrase the INSPIRE statement.
- Keep a home visible after a confirmed privacy objection (see
  `web/src/app/privacy/page.tsx` and `docs/legal/`).

## Personal data

Sale price + address is personal data of the parties to the sale. The lawful
basis, safeguards and objection route are documented in
`docs/legal/legitimate-interests-assessment.md`; the privacy notice is served
at `/privacy`. ICO registration is a deployment step
(`docs/legal/ico-registration.md`).
